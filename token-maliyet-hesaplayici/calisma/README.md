# Çalışma klasörü

Kendi `tokenhesap.py` dosyanı bu klasörde, [Step-by-Step-GUIDE.md](../Step-by-Step-GUIDE.md) rehberini takip ederek yazacaksın:

```bash
python calisma/tokenhesap.py count ornekler/1_kisa_tr.txt
```

Her adımın sonunda dosyanı `cozum/adim_N.py` ile karşılaştırabilirsin. Son adımdan sonra dosyan `cozum/tokenhesap.py` ile aynı işi yapmalıdır.
