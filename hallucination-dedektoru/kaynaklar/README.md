# Kaynaklar

Kurgusal bir şirketin (Kuzey Lojistik) kargo takip API'si için üç Türkçe teknik doküman. Şirket ve API gerçekte yoktur; bu bilerek seçildi. Modelin bu API hakkında eğitim verisinden gelen bir bilgisi olamaz, dolayısıyla yanıttaki kaynakta geçmeyen her ayrıntı tanım gereği kaynak dışıdır (Ders 1.6 §4.1).

| Dosya | Konu |
|---|---|
| `01_kimlik_ve_limitler.md` | Temel adres, API anahtarı, sandbox, hız limitleri, tarih ve para biçimi |
| `02_gonderi_uc_noktalari.md` | Gönderi oluşturma, sorgulama, listeleme ve iptal uç noktaları |
| `03_webhook_ve_hatalar.md` | Webhook olayları, HMAC imzası, yeniden deneme, hata kodları tablosu |

Kendi kaynaklarını eklerken dokümanın bir soruyu tamamen cevaplayan ve kısmen cevaplayan bölümler içermesine dikkat et; kısmi cevap, modelin boşluğu nasıl doldurduğunu görmenin tek yoludur.
