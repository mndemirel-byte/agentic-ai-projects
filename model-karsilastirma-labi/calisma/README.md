# Çalışma klasörü

Kendi `modellab.py` dosyanı bu klasörde, [Step-by-Step-GUIDE.md](../Step-by-Step-GUIDE.md) rehberini takip ederek yazacaksın:

```bash
python calisma/modellab.py run gorevler/1_tek_prompt.yaml
```

Her adımın sonunda dosyanı `cozum/adim_N.py` ile karşılaştırabilirsin. Son adımdan sonra dosyan `cozum/modellab.py` ile aynı işi yapmalıdır.
